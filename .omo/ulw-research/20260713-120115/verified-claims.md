# Verified Claims and Readiness Decision

**Convergence date:** 2026-07-13  
**Repository baseline:** `e9f78180748f1feb428ffb20f9d932c5d9918a48`  
**Exact root Nixpkgs:** `d407951447dcd00442e97087bf374aad70c04cea`  
**Scope:** research and bounded verification only; no production configuration was changed.

## Decision rule

“Ready” means the relevant expression evaluates, the native closure builds, the
installation/activation path passes, and the claimed physical behavior has been
observed on every named support class. Evaluation is not activation, a closure is
not a boot, and a VM is not a physical driver/firmware test. Under this rule, the
repository is a useful x86 workstation baseline, but it is not presently an
“install on any machine and everything works immediately” system.

Evidence references such as `O79` identify rows in `observation-manifest.md`.
Wave artifacts are paths relative to this research directory. “Upheld” and
“narrowed” incorporate the independent Wave 3 skeptic dispositions.
